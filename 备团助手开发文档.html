备团助手 — 开发文档

GM 备团与带团效率工具 · 单文件 HTML 应用 · 无需联网 · 最后更新 2026-06-24

项目简介

备团助手是一款面向 TRPG（桌上角色扮演游戏）GM 的桌面应用，旨在帮助 GM 高效完成备团和带团两个阶段的核心工作。应用基于 Electron 打包为 .exe 桌面版，无需联网，完全离线运行。

工具覆盖 GM 工作流的完整链路：从创建模组、导入 PDF 规则书、编写备团笔记，到在带团过程中使用可视化看板追踪剧情流程、管理 NPC / 线索 / 物品等结构化数据。

模组管理

创建、打开、删除多个独立模组，支持 D&D 5E / 3.5 / COC 7th / 自定义规则系统

PDF 智能导入

解析 PDF 规则书，自动提取文本、识别标题层级、角色数据块、表格，保留原文颜色

富文本编辑器

基于 contentEditable 的完整编辑器，支持格式化、图片、表格、查找替换、目录导航

结构化数据库

15 种分类数据库（角色、线索、场景、物品等），支持搜索、编辑、一键入库

可视化带团板

无限画布 + 流程单元 + 便签卡片 + 连线系统，带团时的实时可视化看板

本地存储

基于 Electron 原生文件系统 API，直写本地 JSON 文件，目录路径跨会话记忆

技术架构

应用基于 Electron 框架打包为桌面版（.exe），核心代码为自包含的单 HTML 文件（约 350KB），不依赖任何外部 CDN 或网络资源。核心技术选型如下：

层面技术说明
运行时Electron 33.x打包为 Windows 桌面应用，菜单栏隐藏，独立窗口运行
主进程Node.js + fs 模块处理原生文件读写、目录选择对话框、配置持久化
渲染进程原生 HTML + CSS + JavaScript无第三方 UI 框架，零依赖
进程通信contextBridge + ipcRenderer/ipcMaincontextIsolation 隔离，通过 electronAPI 桥接调用
PDF 解析PDF.js (pdfjsLib)本地内嵌 pdf.min.js + pdf.worker.min.js
富文本contentEditable + execCommand原生富文本编辑能力
存储Electron 原生文件系统 API主进程通过 fs 模块直写本地 JSON 文件，目录路径持久化
图标内联 SVG Sprite40+ 手绘风格 SVG 图标
画布DOM + SVG 混合便签用 DOM 渲染，连线用 SVG 绘制

StorageManager — 存档管理模块

核心 存储

基于 Electron 原生文件系统 API，直写本地 JSON 文件。主进程通过 fs 模块处理文件读写，工作目录路径持久化存储在 userData 目录的配置文件中。

架构设计

主进程（main.js）

负责原生文件操作，通过 ipcMain.handle 注册 IPC 处理器：pick-directory（目录选择对话框）、list-json-files（列出 JSON 文件）、read-file / write-file（文件读写）、delete-file（文件删除）、check-dir（目录检查）、get-last-dir（恢复上次目录）。配置文件路径：userData/cfpt-config.json。

预加载脚本（preload.js）

通过 contextBridge.exposeInMainWorld 将 IPC 调用封装为 window.electronAPI 对象暴露给渲染进程，保持 contextIsolation 安全隔离。

渲染进程（index.html）

StorageManager 检测到 window.electronAPI 存在后，优先使用原生文件系统方案：AppState.workDirPath 存储工作目录路径，AppState.useFileSystemAPI 标记启用文件系统模式。代码同时保留浏览器 File System Access API 的兼容逻辑（通过 workDirHandle），作为渲染层底子的通用支持。

核心功能

方法功能

pickWorkDir()调用 electronAPI.pickDirectory() 让用户指定工作目录

saveModuleToFileSystem(module)通过 electronAPI.writeFile() 将模组序列化为 JSON 写入文件

PDFProcessor — PDF 智能导入模块

功能 数据

这是本工具最核心的差异化功能之一。以 PDF.js 为底层引擎，对 TRPG 规则书进行深度解析，将 PDF 内容转化为可编辑的富文本格式。

核心原则：文本顺序以 getTextContent() 为准，颜色信息作为附加增强层。

处理流程

读取 PDF → 逐页提取文本与格式 → 双源颜色提取 → 结构分析（标题/角色/表格） → 生成 HTML → 存入模组数据

文本提取与格式增强

  • 逐页遍历 PDF，调用 page.getTextContent() 获取文本项
  • 为每个文本项附加格式属性：字号（从 transform 矩阵计算）、字体名、加粗/斜体标记
  • 自动检测页码行（支持"第X页"、"- X -"、"X / Y"等多种格式）并清除
  • 按 Y 坐标进行行分组（差值 > 3px 为新行），再按行间距进行段落分组

双源颜色提取

源 1：操作符列表法（主要，100% 准确）

遍历 PDF 操作符列表，追踪填充色/描边色/CTM/TextMatrix 以及图形状态栈。支持 RGB、灰度、CMYK（自动转 RGB）、ICC/DeviceN 等颜色空间。在文本渲染操作符处记录位置和颜色。

源 2：Canvas 采样法（辅助）

将 PDF 页面以 4 倍分辨率渲染到 Canvas，对每个文本项中心 15x15 像素区域采样。按亮度排序后寻找最大间隔（谷底），取暗组平均色作为文字颜色。

双源匹配时优先使用操作符列表结果（距离阈值 15px），Canvas 采样补充未覆盖的项（阈值 20px）。接近白色的提取结果会自动降低亮度以保证可读性。

标题识别（多策略融合）

策略规则
书签匹配PDF 自带书签/大纲，文本与书签标题匹配则直接使用书签层级（最大 3 级）
字号比例≥ 1.25 倍正文 → H1；≥ 1.1 倍 → H2；≥ 1.05 倍且加粗 → H3
颜色判断非黑色 + 字号不小于正文 95% + 短文本 → H2
全加粗全加粗 + 短文本 + 字号接近正文 → H3
启发式补充短文本（2-30 字符）+ 无标点 + 非编号 + 后续有较长内容 → 识别为标题

角色数据块识别

专门针对 TRPG 怪物/NPC 数据块的智能识别。当某行命中 2 个以上关键词（护甲等级/AC、生命值/HP、速度、力量、敏捷、体质、智力、感知、魅力、挑战等级/CR、技能、感官、语言、豁免、伤害抗性等）时，自动向前后扩展找到完整数据块，提取各字段值，并将角色名（数据块第一行）和完整数据存入角色数据库。

表格识别

检测 Markdown 风格表格（包含多个 | 的行），识别分隔行（|---|---|），解析表头和数据行，生成完整的 HTML <table> 结构。

PDF 书签处理

调用 pdf.getOutline() 提取 PDF 书签，递归展平为目录结构（最大 3 级），存储在 mod.document.bookmarks 中，用于编辑器目录树渲染和标题识别匹配。

进度反馈

处理过程中显示进度条，实时更新"当前页/总页数 + 处理阶段描述"。完成后显示 Toast 提示，汇总页数、标题数、角色数、表格数。

DocEditor — 富文本编辑器模块

功能 UI

基于 contentEditable 的完整富文本编辑器，是 GM 备团阶段的核心工作区。

文本格式化

功能快捷键说明
加粗Ctrl+BexecCommand bold
斜体Ctrl+IexecCommand italic
下划线Ctrl+UexecCommand underline
删除线—execCommand strikeThrough
标题 H1-H4—工具栏按钮切换
有序/无序列表—execCommand insertOrderedList / insertUnorderedList
引用块—execCommand formatBlock blockquote
水平分割线—execCommand insertHorizontalRule

字体颜色—颜色拾取器，用 surroundContents 包裹实现
行距调整—单倍 / 1.5 倍 / 2 倍 / 自定义，独立撤销栈
缩进控制—增加/减少缩进

撤销与重做

  • 全局撤销/重做基于浏览器原生 execCommand（Ctrl+Z / Ctrl+Y）
  • 行距变更有独立的撤销栈，不干扰全局撤销历史

查找与替换

  • 底部弹出查找替换栏
  • 查找下一个（使用 window.find）
  • 替换当前匹配（替换后自动跳到下一个）
  • 全部替换（通过临时 DOM 节点递归替换，不破坏 HTML 标签结构）
  • 实时匹配计数显示

图片与表格

  • 图片：通过 FileReader 读取为 Base64 DataURL，用 execCommand insertImage 插入
  • 表格：弹出面板指定行列数（行 1-20，列 1-10），自动生成带 thead/tbody 的完整表格

编辑器缩放

通过滑块控制 50%-200% 缩放，使用 CSS transform: scale() 实现，同步调整父容器宽度。

目录树（TOC）

  • 优先使用 PDF 书签数据生成目录；回退方案从 DOM 中提取 H1/H2/H3
  • 点击目录条目平滑滚动到对应标题位置
  • 滚动时自动高亮当前可视区域对应的目录条目
  • 支持折叠/展开

右键上下文菜单

阻止浏览器默认右键菜单，显示自定义菜单，包含：

  • 基础操作：剪切、复制、粘贴
  • 一键入库：将选中文本直接添加到指定数据库（角色、线索、场景、物品等 15 种）

自动保存

输入后 3 秒防抖自动保存，将 innerHTML 和 innerText 写入当前模组文档数据。仅在内容实际变化时触发（脏标记管理）。

工具栏状态同步

监听 selectionchange 事件，实时同步工具栏按钮的激活状态（加粗/斜体/下划线/字号/颜色/行距）。颜色按钮根据背景色明暗自动切换图标颜色。

BoardManager — 带团板管理模块

功能 UI

带团阶段的核心可视化看板，采用无限画布设计，支持流程单元、便签卡片、连线系统等丰富的交互功能。

流程单元（Flow Units）

  • 新增：自动初始化标题、描述、空便签/连线列表和默认视口
  • 删除：二次确认，至少保留一个单元
  • 编辑：双击标题或描述原地编辑，回车/失焦保存，Escape 取消
  • 导航：水平排列，通过轨道位移切换；支持键盘左右箭头；底部缩略图导航条可点击跳转
  • 初始化向导：首次进入时提供"以场景为单元"或"以关键剧情为单元"两种组织方式，从数据库批量生成

便签卡片系统

便签类型

支持 15 种类型（与数据库类型对应），每种有专属图标。创建时通过 5 列网格面板选择类型。

便签内容

根据类型差异化渲染：

  • 角色类型：展示完整数据块（中英文名、体型/类型/阵营、AC/先攻/HP/速度、六项属性、技能/免疫/抗性/感官/语言/CR、特质列表、动作列表）
  • 遭遇/盲盒类型：展示可折叠的骰子范围列表（d最小-最大），每段可编辑内容，支持添加更多范围
  • 其他类型：直接显示文本内容

便签操作

  • 拖拽移动：左键拖拽，支持多选批量拖拽，锁定便签不可移动
  • 拉伸大小：右下角拉伸手柄，最小 120x80
  • 标记已使用：切换 used 状态，视觉上添加半透明样式
  • 锁定位置：锁定后不可拖拽，不可被 Delete 批量删除
  • 双击编辑：弹出编辑窗口，角色类型展示完整数据表单
  • 删除：锁定便签删除需二次确认

连线系统

创建连线

方式一：点击便签头部的连线按钮，进入连线模式，再点击目标便签完成。
方式二：使用工具栏连线工具，依次点击源和目标。
限制：不能自连、不能跨单元、不能重复连线。

连线渲染

使用 SVG 绘制，包含三层：发光层（高斯模糊滤镜）、主连线（可点击）、流动动画点（animateMotion 1.5 秒循环）。提供 8 种预设颜色（金、红、蓝、绿、紫、橙、鲜红、灰）。

擦除连线

进入橡皮擦模式后，点击连线即可删除。连线模式和橡皮擦模式互斥，工具栏显示当前模式指示器。

鸟瞰图 / 小地图

右下角 160x120 像素区域，绘制所有便签的缩略矩形和当前视口范围框。点击任意位置可跳转视口。每次视口变化或便签增删后自动刷新。
