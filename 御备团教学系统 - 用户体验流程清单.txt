## 御备团教学系统 - 用户体验流程清单
### 前置条件（应用启动时）
- 检查 localStorage 中 cfpt-tutorial 记录
- 如果是 首次启动 或 版本升级 （版本号不匹配），弹出"是否开始教学"提示
- 如果已完成/跳过且版本匹配，首页显示"重新教学"按钮
### 第1步：创建新故事
- 用户看到 ：首页，全屏暗色遮罩，高亮框围绕"创建新故事"按钮，气泡提示"欢迎来到御备团！作为GM，第一步是创建一个故事容器。点击'创建新故事'开始。"
- 用户可操作 ：只有"创建新故事"按钮可点击
- 推进触发 ：用户点击"创建新故事"按钮 → 弹出创建对话框 → 自动推进到第2步
### 第2步：导入教学模组
- 用户看到 ：创建对话框打开，高亮框围绕"选择文档"按钮，气泡提示"GM带团离不开模组。点击'选择文档'，在安装目录的 tutorial 文件夹中选择 module.docx。"
- 用户可操作 ：整个创建对话框内所有元素可交互（输入框、选择框、按钮）
- 推进触发 ：用户点击"选择文档"按钮并选择文件 → 文件选择完成 → 自动推进到第3步
### 第3步：创建教学模组
- 用户看到 ：创建对话框中，名字输入框自动填入"酒馆夜话 - 教学"，高亮框围绕"创建模组"按钮，气泡提示"模组名称和游戏系统已经为你预设好了，你也可以根据自己的喜好调整。准备好了就点击'创建模组'。"
- 用户可操作 ：整个创建对话框内所有元素可交互
- 推进触发 ：用户点击"创建模组"按钮 → 故事创建成功 → 自动标记为教学故事 → 进入编辑器 → 自动推进到第4步
### 第4步：归类PL角色
- 用户看到 ：编辑器打开，内容已导入教学模组，高亮框围绕编辑器内容区域，气泡提示"模组里的角色信息应该归到数据库。选中这段PL角色描述'石头 - 矮人战士'，点击右键菜单中的'角色'库。"
- 用户可操作 ：编辑器内所有文本可选中，右键菜单可打开
- 推进触发 ：用户选中"石头 - 矮人战士"文本 → 右键归类到"角色"库（PL类型）→ 事件触发 → 自动推进到第5步
### 第5步：归类敌对角色
- 用户看到 ：高亮框仍围绕编辑器内容区域，气泡提示"同样地，把这段哥布林信息归类到'角色'库。带团时这两类角色是战斗的核心。"
- 用户可操作 ：编辑器内所有文本可选中，右键菜单可打开
- 推进触发 ：用户选中哥布林文本 → 右键归类到"角色"库（敌对类型）→ 事件触发 → 自动推进到第6步
### 第6步：归类CG场景
- 用户看到 ：高亮框仍围绕编辑器内容区域，气泡提示"最后把这段酒馆场景描述归到'主线CG'。CG是你带团时的叙事参考。"
- 用户可操作 ：编辑器内所有文本可选中，右键菜单可打开
- 推进触发 ：用户选中酒馆场景文本 → 右键归类到"主线CG"库 → 事件触发 → 自动推进到第7步
### 第7步：进入带团板
- 用户看到 ：编辑器界面，高亮框围绕"进入带团板"按钮，气泡提示"数据准备就绪！现在进入带团板，那里是你带团时的主战场。"
- 用户可操作 ：只有"进入带团板"按钮可点击
- 推进触发 ：用户点击"进入带团板"按钮 → 切换到带团板页面 → 自动推进到第8步
### 第8步：初始化带团板
- 用户看到 ：带团板初始化向导弹出，高亮框围绕"跳过初始化"按钮，气泡提示"这里有几种快速搭建带团板的方式。教学中我们从零开始体验——点击'跳过初始化'，手搓一个最简单的流程。"
- 用户可操作 ：整个初始化向导内所有元素可交互
- 推进触发 ：用户点击"跳过初始化"按钮 → 向导关闭 → 自动推进到第9步
### 第9步：创建流程单元
- 用户看到 ：带团板空白画布，高亮框围绕"新增流程单元"按钮，气泡提示"GM按场景拆分流程——先建一个'酒馆夜话'流程单元。"
- 用户可操作 ：只有"新增流程单元"按钮可点击
- 推进触发 ：用户点击"新增流程单元"按钮 → 流程单元创建成功 → 自动推进到第10步
### 第10步：打开数据库面板
- 用户看到 ：带团板画布上有流程单元，高亮框围绕工具栏"数据库"按钮，气泡提示"点击工具栏的'数据库'按钮，打开数据库面板。刚才归类的数据都在这里。"
- 用户可操作 ：只有"数据库"按钮可点击
- 推进触发 ：用户点击"数据库"按钮 → 数据库面板打开 → 自动推进到第11步
### 第11步：拖入便签元素
- 用户看到 ：数据库面板已打开，高亮框围绕数据库面板，气泡提示"现在把刚刚归类的数据拖到画布上：从数据库面板里，找到CG便签、PL便签、敌对便签各拖一个到画布上。这就是你带团时的场景布局。"
- 用户可操作 ：数据库面板可交互（滚动、点击），画布区域可接收拖拽
- 推进触发 ：用户成功拖入3个便签（CG、PL、敌对各一个）→ 事件触发 → 自动推进到第12步
### 第12步：连线串联逻辑
- 用户看到 ：画布上有3个便签，高亮框围绕"连线模式"按钮，气泡提示"GM的流程是有逻辑的：用连线把便签串起来，形成带团时的推进链路。点击'连线模式'按钮开始连线。"
- 用户可操作 ："连线模式"按钮可点击，画布区域可点击（用于连线操作）
- 推进触发 ：用户在连线模式下完成2条连线 → 事件触发 → 自动推进到第13步
### 第13步：添加战斗模块
- 用户看到 ：画布上有便签和连线，高亮框围绕"战斗模块"工具按钮，气泡提示"遭遇战是DnD的核心。添加一个战斗模块，把PL便签和敌对便签'加入先攻序'，填上先攻值（石头=18，哥布林=12）。"
- 用户可操作 ："战斗模块"按钮可点击，画布区域可操作（放置战斗模块、添加先攻序）
- 推进触发 ：用户成功添加2个战斗参与者（石头和哥布林）→ 事件触发 → 自动推进到第14步
### 第14步：完成一轮战斗
- 用户看到 ：战斗模块已打开，高亮框围绕"攻击"按钮，气泡提示"开始带团！选中石头→对哥布林发起攻击；再给哥布林施加一个'流血'状态；最后点'结束回合'。这就是你带团时的核心循环。"
- 用户可操作 ：战斗模块内所有元素可交互（攻击按钮、状态按钮、结束回合按钮、先攻序列表）
- 推进触发 ：用户点击"结束回合"按钮 → 回合结束事件触发 → 教学完成
### 教学完成
- 用户看到 ：教学完成弹窗，金色粒子飘散动效，提示"恭喜完成教学！你已经掌握了御备团的核心功能。"
- 用户可操作 ：选择"保留教学故事"或"删除教学故事"
- 状态保存 ：记录教学完成状态和当前版本号到 localStorage
### 全局控制（贯穿始终）
- 暂停菜单 ：按 Esc 键或点击气泡旁的关闭按钮 → 弹出暂停菜单（暂停/继续/跳过/重新开始）
- 进度保存 ：每步完成后自动保存当前进度，支持中断后继续
- 重新开始 ：首页"重新教学"按钮，清除进度后重新开始
这个清单涵盖了所有14步的用户体验细节，包括：

- 每步用户 看到什么 （视觉状态）
- 每步用户 能操作什么 （交互范围）
- 每步 如何推进 （触发条件）
- 全局控制功能
